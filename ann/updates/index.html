2.22 更新公告

Section titled “2.22 更新公告”

主要更新内容:

Section titled “主要更新内容:”
  • 主页新增问候语。
  • 控制台新增导出日志按钮。向开发者反馈问题时请使用此功能导出日志并发送给我们。
  • 新增task reload命令，支持在控制台中热重载任务。
  • 新增自动演奏扩展，支持按 JSON 乐谱自动在游戏内使用乐器演奏，支持鸣潮、异环、原神等游戏。
  • 新增更新下载目录配置项，支持自定义安装包保存路径。
  • 新增重新安装最新版本功能，用来修复文件损坏等问题。

问题修复：

Section titled “问题修复：”
  • 优化登录逻辑，修复了b服无法自动登录的问题。
  • 修复了因无法删除旧可执行文件而导致的检测更新、拉取公告失败的问题。
  • 修复了特殊情况下读取领取奖励配置失败的问题。
  • 修复了货币战争中当金币不足时处理命运卜者事件陷入死循环的问题：现在所有事件默认选择最后一个选项。

更新说明：

Section titled “更新说明：”

新增自动演奏扩展：

Section titled “新增自动演奏扩展：”
  • 新增自动演奏扩展，支持按 JSON 乐谱自动在游戏内使用乐器演奏，支持鸣潮、异环、原神等游戏。
  • 可以配置自动演奏扩展的参数，如乐谱文件路径、演奏速度、演奏次数等。
  • 需要先进入游戏的演奏界面，再启动自动演奏扩展，在指定时间内切回游戏界面。
  • 按 F8 暂停自动演奏，按 F10 重置自动演奏，按 F9 停止自动演奏。
  • 乐谱文件存放于扩展目录下的scores文件夹中。

Section titled “2.21 更新公告”

  • 调整了清体力“历战余响”的自动检测逻辑，现在当它启用自动检测时视为挑战3次。

  • 修复了货币战争中无法处理命运卜者事件的问题。 #234
  • 修复了货币战争中自动战斗情况下前后台角色均无法造成伤害时，卡死在奖励关卡的问题。 #233
  • 修复了差分宇宙/货币战争中当点击前往参与后未直接进入主界面导致任务无法正常运行的问题。
  • 修复了自动对话无法跳过对话的问题。
  • 修复了云游戏模式下无法切换账号的问题。
  • 修复了货币战争中特殊情况下无法输入攻略码的问题。
  • 修复了差分宇宙选择面具时有刷新按钮导致无法选择面具的问题。
  • 修复了货币战争中当选择了阿哈大悦策略后卡死的问题。
  • 修复了国际服无法自动登录的问题。
  • 修复了货币战争标准/超频博弈任务结束后崩溃的问题。

  • 如果你在更新后发现问题依然存在，请及时反馈给我们。

更新说明：

Section titled “更新说明：”

新增operator命令

Section titled “新增operator命令”
  • 新增operator命令，用于直接调用SRA的Operator API以实现游戏操控。
  • operator list - 显示所有可用的Operator API。
  • operator call - 调用指定的Operator API，参数为JSON格式。
  • operator help - 显示指定Operator API的详细帮助信息。
  • SRA Server同步更新。

内置SRA ServerDLC

Section titled “内置SRA ServerDLC”
  • 为了减少用户下载时的疑惑和提供统一的使用体验，不再单独分发SRA ServerDLC，而是包含在主程序包中。
  • 但要使用SRA-server，你必须安装ASP.NET Core 运行时 10.0。或.NET SDK 10.0。

SRA MCP服务器

Section titled “SRA MCP服务器”
  • 在此版本中新增了SRA MCP服务器，为agent接入提供了基础支持。
  • 启动SRA Server后，在Agent中配置http://host:port/mcp，并以流式HTTP方式访问即可。
  • 服务器提供了一组精选的MCP工具，用于与SRA或游戏本身进行交互。这些工具包括但不限于：
    • 获取游戏截图与OCR识别
    • 模拟输入
    • 任务列表
    • 其他自定义工具

更新说明：

Section titled “更新说明：”
清体力逻辑变更
Section titled “清体力逻辑变更”
  • 清体力逻辑变更，任务清单与培养目标不再互斥。
  • 具体的副本添加顺序：由多倍活动检测添加的 -> 由培养目标添加的 -> 由任务清单添加的。
拓展系统：
Section titled “拓展系统：”
  • 新增拓展系统，支持自定义插件和脚本。
  • 拓展系统旨在以最小的侵入或对主程序的修改，实现动态加载自定义插件和脚本的功能。
  • 只需按固定模式编写python脚本，即可在SRA中动态加载和运行，自动生成可视化配置界面。
破坏性变更：
Section titled “破坏性变更：”
  • 移除了旧版触发器系统，现在由拓展系统替代。
  • trigger及它的子命令已被移除，现在由拓展系统替代。
  • 示例：
    • 旧 trigger enable <extension_id>
    • 新 extension run <extension_id>
    • 旧 trigger disable <extension_id>
    • 新 extension stop <extension_id>

更新说明：

Section titled “更新说明：”
在攻略中指定特殊事件处理策略
Section titled “在攻略中指定特殊事件处理策略”
  • 货币战争攻略新增 special_events 字段，用于指定特殊事件的选择。
  • 支持的特殊事件有：领航员、盛会之星、头号玩家、命运卜者。
  • 格式：特殊事件名称: 选择，选择为选项中的视觉文本。
动态新增cli命令

    • tpconfig - 获取清体力副本数据

清体力副本数据使用统一的数据源
Section titled “清体力副本数据使用统一的数据源”
  • 此前我们在前端和后端分别维护两份清体力副本数据，非常容易导致数据不一致的问题。
  • 现在我们统一了数据源，前端启动时会从后端获取最新的清体力副本数据，确保前后端数据一致。
  • 如过您发现更新后前端下拉列表中缺少某些副本，或完全为空，请及时与开发者反馈，我们会尽快修复。

货币战争刷开局投资策略输入格式调整：
Section titled “货币战争刷开局投资策略输入格式调整：”
  • 现在支持在输入框中输入两个位面分别的投资策略，使用分号分隔，格式为：位面1投资策略;位面2投资策略，支持中文分号。
  • 例如：轮回不止；环保大使叽米 表示在第一位面刷取“轮回不止”策略，在第二位面刷取“环保大使叽米”策略。
  • 前一个策略满足条件后才会开始刷取后一个策略。
  • 如果只输入一个策略，则默认在第一位面刷取该策略，第二位面不刷取任何策略。
  • 如果想要在第二位面刷取策略但不在第一位面刷取任何策略，可以输入;位面2投资策略，例如：;环保大使叽米。
