Section titled “更新说明：”

热更新

Section titled “热更新”
  • 当新版本与当前版本属于同一大版本、同一小版本，仅是补丁版本更高，且远端提供热更新清单时，SRA 会优先使用热更新：只下载并替换发生变化的源码、任务、扩展、资源与入口文件，完成后自动重启后端。
  • 热更新不可用（例如跨版本更新、Beta 版本或清单缺失）时，会自动回退到完整更新。
  • 热更新不包含桌面端程序本身；涉及桌面端改动的版本仍需完整更新。

命令面板

Section titled “命令面板”
  • 按下 Ctrl+Shift+P 打开命令面板。

Section titled “cli 新增 serve 命令”

SRA-Cli 与 SRA-Server 现在是一款统一的产品

Section titled “SRA-Cli 与 SRA-Server 现在是一款统一的产品”

我们已将 SRA-Cli 与 SRA-Server 合并为一款统一的产品，所有功能与之前相同。 你可以通过 SRA-cli.exe serve 命令启动服务端，而无需额外安装 ASP.NET Core。

服务端配置：

  • 优先级：命令行参数 > 环境变量 > SRAServer/server.toml > 默认值。
  • 可用键：SRA_HOST、SRA_PORT、SRA_WEBUI、SRA_ACCESS_TOKEN、SRA_VISITOR_MODE、SRA_LOG_LEVEL（server.toml 中为同名小写键）。
  • 命令行参数：--host（绑定 0.0.0.0 对外暴露）、--port；sra serve 另支持 --no-webui
  • Core / Full / Lite 发行包均已内置 WebUI，开箱即用；通过 uv / pip 安装（wheel 不含构建产物）时需执行一次 sra init 下载 WebUI，未下载时 REST 与 MCP 仍可用，只是没有 Web 界面。

Section titled “新增 Docker 部署支持”

SRA 现在支持 Docker 部署，详见 Docker 部署说明。

破坏性变更:

Section titled “破坏性变更:”
  • 打包方式变更：不再使用Nuitka打包，而是直接嵌入 Python 运行时。
  • Server: 移除了 SRA-server.exe, 请使用 SRA-cli.exe serve 启动服务端。
  • Server: 服务器 REST 路径统一为小写。
  • Server: 远程模式默认地址改为 http://localhost:5073（原 5000），请求路径同步改为 /api/**。
  • Server: 不再需要 ASP.NET Core。
  • Core: Python 依赖分组 full extra 更名为 standard：pip install ".[full]" 失效，改用 pip install ".[standard]"。
  • Extensions: 扩展改为目录包（一级目录 + __init__.py）才加载，旧的单文件 extensions/xxx.py 只记录 warning 后忽略。 第三方扩展需迁移为 extensions/<名称>/__init__.py，原文件内的相对导入与同目录资源一并移入该目录。

自定义后端说明

Section titled “自定义后端说明”
  • 设置页「开发者」区域的「启用自定义后端」现支持三个配置项：
    • 命令/可执行文件：如 python、sra-cli、uv，或可执行文件的完整路径（含 /、\ 时校验文件存在，PATH 命令交由系统解析）。

  • 常见组合：

    • 模块运行：命令 python + 参数 -m SRACore
    • pip 安装后：命令 sra-cli + 参数留空
    • uv 运行：命令 uv + 参数按需填写

货币战争-刷开局说明

Section titled “货币战争-刷开局说明”
  • 货币战争-刷开局现在使用正则表达式匹配，以实现更丰富的匹配逻辑。
  • 通用规则：
    • 匹配前会对文本做清洗（去除空格、·、•、?，全角字符归一化为半角），配置时无需处理这些 OCR 干扰字符。
    • 配置串作为正则对识别文本做 re.search 搜索，即识别文本中包含能被该正则命中的片段即算匹配，不要求整串相等。
    • 正则特殊字符（.、+、*、(、)、[、] 等）有特殊含义，需匹配字面本身时请用 \ 转义；请确保输入为合法正则，否则配置阶段会报错。
    • 投资策略、Boss名称、Boss词缀的配置在匹配前会移除 ?，因此这些项中不能使用 ? 量词（如 \+?），可用 | 交替代替；投资环境的 ? 仅在开头表示“可选项”前缀。
    • 分隔符全角/半角均可（自动归一化）。
  • 正则语法速查：
    • . 匹配任意单个字符；* 出现 0 次或多次；+ 出现 1 次或多次（字面 + 必须写成 \+）。
    • | 表示“或”；() 分组；[] 字符集；^/$ 匹配文本开头/结尾。
  • 示例：
    • 投资环境：空格分隔；不带前缀为必须项（正则匹配），? 或 ？ 前缀为可选项（正则匹配）。先匹配必须项，都没有时再匹配可选项；全部未命中则尝试刷新，无法刷新且存在必须项时重开。
      • 人才储备：必须命中“人才储备”。
      • .*概念股：命中任意概念股环境（仙舟/减益/击破/列车同行概念股），.* 表示任意长度的任意字符。
      • 人才储备 ?.*邀请：必须命中“人才储备”；可选项命中“仙舟邀请”“击破邀请”“减益邀请”等（开头的 ? 是可选前缀，其后内容才是正则）。
    • 投资策略：分号 ; 分隔，按顺序对应阶段1、阶段2…，每阶段为正则匹配；该阶段留空表示无要求，末尾分号表示该阶段满足后立即停止刷开局。
      • 长期主义|加油站|彩虹期货：阶段1命中三者之一即可，| 表示“或”。
      • 固定理财\+：只匹配“固定理财+”；直接写 固定理财 则带不带”+“都能命中，\ 将 + 转义为普通字符。
      • ^特战资金$：只匹配不带”+“的”特战资金”，^/$ 要求整段识别文本完全一致。
      • .+星徽：命中任意星徽类策略（列车同行星徽、银河学者星徽、击破星徽…）。
      • 长期主义;.+星徽：阶段1命中“长期主义”，阶段2命中任意星徽。
    • Boss名称：分号 ; 分隔，最多三个，依次对应第一、二、三位面，每项为正则匹配；不足三个时，未填写的位面不作要求。名称取自竞争对手一览的“名称”栏。
      • 凛冬经贸联合体;铁盾安保集团;深穹智械科技：三位面分别指定竞争对手。
      • 凛冬|火线;铁盾;造梦：借助搜索匹配，无需写全名，| 可给出多种候选。
      • 冷锋兵器工业;;造梦：第二位面不限。
    • Boss词缀：空格分隔；不带前缀为必需词缀（必须全部命中），! 或 ！ 前缀为仇恨词缀（出现任一即重开），均为正则匹配。优先级：仇恨词缀 > 必需词缀。
      • 首领强化 一鼓作气 !熄火：必须同时命中“首领强化”与“一鼓作气”；出现任意含“熄火”的词缀（前台熄火、后台熄火、风之熄火…）即重开。
      • 侵蚀：命中任意“侵蚀•XX强化”类词缀（• 会被自动移除，无需手动处理）。
      • 第一位面强化|第二位面强化：命中两类位面强化词缀之一即可。
  • 与旧版本的差异（破坏性）：
    • 旧版为双向子串匹配（配置与识别文本互为子串即命中），现改为单向正则搜索，配置串作为正则作用于识别文本。
    • 旧配置中的正则特殊字符（如 .）会改变匹配含义，必要时请转义。

Section titled “SRA-WebUI 说明”
  • SRA-WebUI 是一个基于 Vue 3 的 Web 应用，用于提供 SRA 的 Web 用户界面，使你可以通过浏览器访问 SRA 的功能。
  • 它需要 SRA-server 才能正常工作。
  • 启动SRA-server后，SRA-WebUI会自动启动，你可以在浏览器中访问 http://localhost:5000 来查看 SRA-WebUI。
  • 如果不需要使用SRA-WebUI，你可以在启动SRA-server时添加 --no-webui 参数来禁用它。
  • 如果要更改监听端口，你可以在启动SRA-server时添加 --urls http://localhost:{port} 参数来指定监听端口。
  • 如果要让SRA-server在所有网络接口上监听，你可以在启动SRA-server时添加 --urls http://0.0.0.0:{port} 参数。

远程后端

Section titled “远程后端”
  • 桌面端新增远程后端模式，可通过HTTP连接远程SRA服务端执行任务。
  • 在高级设置中可启用远程后端并配置服务器地址（默认 http://localhost:5000）。
  • 连接后自动订阅服务端SSE日志流，实时显示远程任务输出。
  • 支持通过 Task/run 和 Task/stop API 启动和停止远程任务。
  • SSE断线后自动重连（3秒间隔）。
