其他获取方式

除官方 Release 外，也可以通过下列渠道安装或更新。

Mirror酱第三方加速分发，也负责后续自动更新；仅对加速服务收费，SRA 本身免费。GitHub Releases官方发布渠道，包含全部发行包与历史版本。夸克网盘国内网盘备份，版本可能滞后，建议优先使用上面两种方式。

通过 PyPI 安装

适用于 Windows、Linux 与 macOS，需要 Python 3.12。安装后执行 sra init 下载 WebUI 与核心资源。

uv tool install starrailassistant
sra init
sra serve
查看完整安装步骤

用 Docker 部署

镜像只包含 SRA-server（WebUI、HTTP API 与 MCP），容器内只能使用云游戏。

docker run -d --name sra-server -p 5073:5073 \
  -e SRA_ACCESS_TOKEN=<token> \
  ghcr.io/shasnow/starrailassistant:latest
查看部署指南
