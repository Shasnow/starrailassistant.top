This section explains how to run the SRA CLI from source.

## Prerequisites

- Python 3.12 (the project requires `>=3.12, <3.13`; 3.13 is not supported yet)
- Git

## Step-by-Step Tutorial

<Steps>

1. Clone the repository:
    ```bash
    git clone https://github.com/Shasnow/StarRailAssistant.git 
    ```
   If cloning is slow, consider a shallow clone:
    ```bash
    git clone https://github.com/Shasnow/StarRailAssistant.git --depth=1
    ```
2. Enter the project directory:
    ```bash
    cd StarRailAssistant
    ```

3. Create and activate a virtual environment:
    ```bash
    python -m venv .venv
    .venv\Scripts\activate
    ```

4. Install the project and its desktop dependencies in editable mode:
    ```bash
    pip install -e ".[standard]"
    ```
   `standard` includes the keyboard/mouse simulation, clipboard, notification, and other dependencies required by the desktop client; to run the server (WebUI / HTTP API / MCP), use `.[server]` instead.
   If installation is slow, consider a domestic mirror, such as the Tsinghua PyPI mirror:
    ```bash
    pip install -e ".[standard]" -i https://pypi.tuna.tsinghua.edu.cn/simple
    ```

5. Run SRA:
    ```bash
    python main.py
    ```
   After installation, you can also use the command-line entry point directly:
    ```bash
    sra
    ```
   This brings you into SRA's interactive command-line interface. You should see output like the following:
    ```text
    # ... 这些是一些调试信息
    欢迎使用 SRA-cli（版本 2.26.0，内核 2.26.0 on win32）。
    输入 'help' 查看命令列表。
    sra> 
    ```

6. Run tasks or perform other operations:
   See the [SRA-cli](/en/cli/simple-usage) chapter to learn how to use SRA-cli.

7. Try it out:
    - Run the `help` command to view the available commands.
    - Run the `version` command to view the current SRA version.
    - Run the `exit` command to quit SRA-cli.

</Steps>

## FAQ
- SRA prints `WARNING | 您没有以管理员权限运行 SRA-cli。某些命令可能无法正常工作。`:
    - Consider running the terminal as administrator, then repeat step 5.
    - If you use an IDE such as PyCharm, make sure to run the IDE as administrator.
    - Alternatively, use `--no-admin` to disable this check.
