## Random greetings

SRA displays a random greeting at startup. Here is the current list of greetings:

| Chinese | English | Explanation |
| --- | --- | --- |
| 欢迎使用 SRA！ | Welcome to SRA! | An ordinary greeting. |
| 坐和放宽 | Sit back and relax | An internet meme from 2015, produced by a machine-translation error on the installation screen of the Windows 10 preview build. |
| 并非'Sequence Read Archive' | not 'Sequence Read Archive' | SRA's full English name is StarRailAssistant, which shares its name with a biology database called Sequence Read Archive. Joining the chat group also requires answering what SRA stands for, and quite a few people were turned away for answering Sequence Read Archive |
| 启动器启动启动器 | Launcher launching launcher | A reference to the achievement "合成器合成合成器" in the game Minecraft. Early versions of SRA needed a launcher to launch the b server. |
| -1073741819 | -1073741819 | The return value when a Python program crashes; this error means the program hit a memory access violation. SRA used to be plagued by this problem. |
| 飞荧扑火，向死而生 | | A line from the character Firefly in the game Honkai: Star Rail. |
| 跨越寰宇终抵黯淡星外 | | Lyrics from "致暗淡星", a fan-made song inspired by the Honkai: Star Rail story "致暗淡星". |
| 立志成为崩铁糕手 | | A user submission |
| 满月是神不在的时间 | | The title of Honkai: Star Rail version 4.0. |
| Bon voyage | Bon voyage | French for "have a good journey". Lyrics from "远航星的告别", the soundtrack of the "旅途愉快" cutscene in Wuthering Waves. |
| May your path be clear | May your path be clear | Lyrics from the song "远航星的告别". |
| May you get to where dreams are all crystalline and sweet | May you get to where dreams are all crystalline and sweet | Lyrics from the song "远航星的告别". |
| 我们将在过去篆刻未来 | We will make the past with the future | A line from the "人类的'心脏'" cutscene in Wuthering Waves |
| 铁花飞，飘逸不残灰 | | Lyrics from the song "铁花飞". |


If you have more ideas for creative greetings, feel free to contact us and submit them!

## Special backgrounds

Entering specific content in `背景图片路径` (Background image path) in Settings triggers a special background. The
currently supported special backgrounds are:

| Special background | Explanation |
| --- | --- |
| shasnow | Displays the character art of `雪影`, SRA's lead developer |
