## Usage Notes

#### ⚠️ Important

- 📺 **Resolution requirements**:
  - If your screen resolution is **greater than 1080p**, run the game in **1920x1080 windowed mode**, otherwise recognition errors may occur!
  - If your screen resolution **equals 1080p**, run the game in **1920x1080 fullscreen** mode, otherwise recognition errors may occur!
- 🖱️ **Operation tip**: **Do not perform other keyboard or mouse operations while a task is running!**

## Cloud Honkai: Star Rail Compatibility Testing!

#### Cloud Honkai: Star Rail compatibility:

- Enable it in settings; currently only the Microsoft Edge browser is supported, so make sure Microsoft Edge is installed on your system.
- You must check the launch-game task and fill in the account and password.
- Recommended when you have a Cloud Play card or idle cloud game time.
- Known issues:
  - The browser does not close automatically after the task ends; close the browser window manually.
  - Currently only the Microsoft Edge browser is supported; other browsers may not work properly.
  - You may encounter login issues; make sure the account and password are correct and the network connection is stable.
  - Auto-battle and speed-up are not enabled.
