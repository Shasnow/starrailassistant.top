## Contributing
If you would like to help maintain StarRailAssistant, you are welcome to join us through the options below.

### What you can do

- File bug reports to help us locate problems faster.
- Submit pull requests to fix bugs or add features.
- Improve the documentation so that new users can get started more easily.
- Take part in testing and report how things behave on different devices and environments.

### How to get involved

1. Open the repository on GitHub and look through the existing issues.
2. If you find a problem, file a clear issue first, describing the reproduction steps and attaching screenshots.
3. If you are willing to fix it yourself, you can fork the repository and submit a PR.
4. If you just want to help, feedback and suggestions are welcome too.

### Contributions we especially welcome

- Documentation additions and corrections
- Proposals for new features
- Optimizations related to image recognition
- Testing feedback from different resolutions and system environments

### Contact and collaboration

If you are already contributing, please keep each change as focused as possible and avoid touching too much
unrelated content in a single PR. This makes it much easier for us to review and merge quickly.
